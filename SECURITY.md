# Security

Do not submit merchant exports, customer messages, credentials, access tokens,
store identifiers, or unpublished product data in an issue or pull request.

This lab is dry-run software. Platform execution remains disabled until OAuth
scopes, retention, human approval, and incident handling are reviewed for a
specific merchant and platform account.

Before opening a pull request, run:

```powershell
npm run verify
```

Security reports should be sent privately to the repository owner after a
private contact method has been configured. No public security contact is
embedded in this repository.
